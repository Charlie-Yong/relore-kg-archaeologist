# relore 项目历史知识图谱｜六人 AI 执行规划

基于 relore 的开源项目历史可追溯知识图谱构建与应用，以 Flask 为首选试点。

本仓库已按用户授权公开，规划可直接阅读；提交和管理仍按实际授权。密钥、私有测试参考和个人材料不在公开仓库中保存。

**当前交付：规划 v1.1 / 契约 1.1.0。** 仓库内是总方案、接口约定、六人工作单和状态模板；系统实现、真实数据、模型调用、图库和正式实验均待后续执行。

## 成员如何开工

首次把本人对应的一份完整工作单交给AI；AI已有仓库访问时，给该文件路径即可。文件已经指定角色和本轮首个可运行产物，AI读完即自行读状态、检查环境、恢复/建立个人分支并开始实施，不需要额外启动提示或回答“是否开始”。只收到通用规划且无法唯一确定角色时才询问分工。

后续恢复会话时，AI自行读取STATUS、最新交接、请求和现有成果，接着做下一项可执行工作。缺上游先登记请求并推进独立任务；常规提交、审核、技术确认、集成、报告和PPT都由角色AI完成。当前交付仍是规划资料，本次维护不冒充六个模块已开始运行。

| 角色 | 工作单 |
|---|---|
| P1 数据与集成 | [P1工作单](P1_数据与集成_给成员AI.md) |
| P2 图谱与查询 | [P2工作单](P2_图谱与查询_给成员AI.md) |
| P3 代码与演化 | [P3工作单](P3_代码与演化_给成员AI.md) |
| P4 模型与知识抽取 | [P4工作单](P4_模型与知识抽取_给成员AI.md) |
| P5 原型与汇报 | [P5工作单](P5_原型与汇报_给成员AI.md) |
| P6 模型参考与实验 | [P6工作单](P6_模型参考与实验_给成员AI.md) |

P4使用macOS，其余Windows；P2使用现有DeepSeek可执行开发工具，其余五人Codex；全员已有DeepSeek API。除确需本人接管的环节外，全部项目工作交给AI。成员只处理本人登录/权限、缺少或超出已批预算的费用决定、必要设备动作、理解与现场表达和真实互评。代码、配置、数据核验、评分、交接、报告/PPT与打包均由AI执行；不安排逐条人工标注评分。

“自动开工”指AI在已经打开且具备相应工具权限的会话中读到工作单后直接执行；仓库文件不负责启动另一台电脑或唤醒已结束的会话。会话恢复后AI按记录自行续做，不要求成员重述方案。

## 检查规划资料

以下两个脚本只维护文档，不代表系统运行通过：

~~~text
python tools/sync_workorders.py
python tools/check_planning.py
~~~

Windows可使用py -3运行，macOS可使用python3。工具仅用Python标准库。六份工作单的公共段必须与统一契约一致，状态文件中的后续实现不得提前标完成。
