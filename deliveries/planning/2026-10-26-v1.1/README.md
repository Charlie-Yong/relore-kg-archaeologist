# v1.1 AI全面接管与自动开工修订

2026-10-26｜规划v1.1 / 契约1.1.0。

用户要求：除确需本人接管的环节外，全部项目工作交AI；每个AI读本人规划就理解角色并自动开始。本轮只修订规划与协作入口，不启动六个课程实施模块、不运行真实采集/LLM/数据库/实验。

## 已完成的文档改动

- 六份完整工作单各有角色明确的自动开工段：定位仓库、读STATUS/交接、恢复分支、检查能力后执行本轮首个可运行产物，不止输出计划。
- 公共契约区分AI工作与最小人工接管，角色名默认指对应AI。常规技术确认、环境排错、Git、交接、内容审核、报告/PPT与打包均由AI完成。
- 所属AI直接登记依赖请求，P1的AI主动查交付/请求/PR并处理；缺上游推进独立任务，不要求成员传话。
- 同步README、AGENTS、总规划、成员登记、请求/能力说明、状态和交接模板；模型批次在已批预算内直接执行。
- 明确会话恢复由AI自行读记录，活跃会话自动续做；没有声称文档能启动离线电脑或后台调度。
- 技术范围、数据Schema、私有测试隔离、六人环境、模型配置原则及课程日期保持。六模块状态仍为todo。
