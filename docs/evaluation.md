# 独立参考与实验

P6维护`historykg/evaluation`，生产采集、图与回答接口仍由P1/P2/P4负责。
命令`python -m historykg.cli evaluate score <records.json> --out <metrics.json>`
直接从保存的逐项判断重算，无需模型调用。`evaluate freeze`只读取来源、主体与元数据。
`python -m historykg.cli evaluate summarize <qa_metrics.json> --split test --out <summary.json>`
从逐题指标重算汇总和配对统计，亦不调用模型；正式发布后以配套逐项记录复核输入指标。

## 冻结和隔离

正式来源选择先于生产预测。公开的[只依赖来源的清单](../evaluation/results/source_only_freeze.json)
登记369份冻结来源的类型/哈希、40完整线程的10dev/30test划分和12文件×SHA的4dev/8test。
旧诊断及关联QUERY、流上下文线程归开发集；Cloudflare等显式关联线程保持同一划分。
代码测试取pytest兼容主题的两文件前后四快照和当前版本四个小模块，开发取IPv6主题两文件
前后四快照。快照不是版本对计数，未根据预测成功率删样本。

测试问题、模型银标、复核、原始请求响应、盲化映射及逐项评分从首次生成起位于
`evaluation/private_test/<dataset>/`，被Git忽略。reference/judge从prepare阶段强制此路径，
生产extract/answer拒绝读写此缓存。问题先保存ID/正文，随后另请求生成参考及独立复核；
生产只获得同一question_id/正文与正常解析字段，不获得分类、来源提示或可回答标签。

## 独立模型参考

完整线程批参考读取正文、全部普通评论、review与inline来源，并使用同一subjects目录。
参考先于生产正式抽取；独立复核重新从完整原文枚举，再对照草稿修正遗漏、归属、主体、
动作、采用状态与明确理由，保留分歧和unclear。所有引文程序核对原文及唯一位置。
无法确定项目的候选保留，不静默删掉；参考范围无法评估时总体指标为N/A。
这些是独立请求生成的模型参考/银标，不是人工金标，也不表示模型误差相互独立。

实际开发负例保留在`evaluation/dev/semantic_negative_result.json`：结论支持性3/3符合
预期，但严格的结论/理由双标签为0/3，因为judge把三个空理由判为unclear而非unsupported。
计分器直接依据空理由保留零覆盖；另有开发参考遗漏测试调整决策的分歧。不能据格式检查
或成功返回宣称语义负例全过，也不回填参考消除这些已保存的分歧。

证据不足候选对整个369来源池（含全部代码、API JSON、git输出和发布说明）做两次独立分片
核验。每个原文码点覆盖，分块400码点重叠；保存来源哈希及覆盖清单。首轮92个位置中86个
成功、6个结构或引文失败；只对失败位置沿原分片和缓存做一次格式恢复重试后，最终92/92
完成两遍核验。6个候选均有非空证据，确认不足题仍为0，故正确弃答率为N/A，原因是合格
分母为0，而不是核验不完整。未完成覆盖仍不得计为已确认不足。

## 计分

抽取以项目、主体、动作、采用状态和结论的语义匹配为前提，理由单独判断。程序做最大
一对一匹配；在同样TP数的匹配中优先保留已支持的完整理由，最后按稳定ID处理同分。
重复预测为FP，缺失参考为FN，生产空输出或失败不会移走FN。所有预测须有评审，漏评
总体P/R/F1为N/A。TP=FP=FN=0为N/A；有参考而全漏时F1=0。
理由分母是全部明确stated的有效参考；整条漏抽、空理由和部分理由均保留。开发验收例：
两条参考均有理由，只命中一条且重复预测一次、理由都空，TP/FP/FN=1/1/1，P/R/F1=.5，
理由覆盖0/2。此合成计数不属于Flask正式结果。

代码核验先从原始冻结源码独立生成静态参考，再核对P3的解析状态、顶层符号、docstring，
以及已发出Imports的原文语句与同SHA。仅报告12个快照范围；不报告事件召回，也不宣称
未采依赖完整或代码已运行。

QA对匿名A/B全部claims及全部参考原子事实逐项判断，漏项不当零错误。事实覆盖针对可回答
题；证据组召回只按实际送入模型的最终context.fragments完整区间计数，截断前候选不计。
无依据断言率的分母是全部返回claims，unclear单列；运行失败与正确弃答分别统计。
公开汇总包含原始分子分母、错误/弃答/运行和评审覆盖、耗时、token及保守费用估算。
配对问题bootstrap仅描述本小范围，不能当作独立主题总体泛化保证。

## 第二仓库免改代码检查

另以未硬编码的公开Python仓库`pallets/itsdangerous`运行同一默认profile和同一URL入口，
不手选线程/SHA、编辑关系或补采来源。作业生成347份来源、30个完整讨论单元、82个实体、
78条关系及180条证据，校验状态ok，图与检索均就绪。`dependencies`问题经公共查询入口返回
50条路径、25条证据和5条有出处claims；引文均可回查冻结原文，来源哈希复算一致。采集还
保留10次HTTP 404和147个未补采显式引用，因此作业状态为partial，而不是宣称无损。两次
查询为一题ok、一题empty，至少一题实答满足轻量迁移检查，但单库结果不外推为任意仓库通用。
完整逐项状态见
[final_acceptance.json](../evaluation/results/final_acceptance.json)：P6可执行的实验、
证据、全池和第二库项目为pass或带记录缺口的pass；课程级整合报告、PPT及Windows运行
仍为not_verified，外部接收方签收不由P6自称完成。

## 公平对照与费用

A为固定relore检索底座与共同补充来源适配，B复用同底座并作图扩展；两组用同来源、
主体解析、DeepSeek模型/提示/参数和12000 Unicode码点最终上下文预算。排序、去重、
裁剪由同一render_context完成。保存候选、最终实际prompt、原始响应、盲化顺序及全部claims。

本轮模型配置deepseek-flash、thinking disabled、temperature 0、max_output_tokens 4096、
最多2次有界重试。P6评审提示及配置独立版本化。所有角色/任务使用同一持久费用账本，现
授权20元、有效上限19.84元；失败、重试及用量未知请求均入账。最终保守累计9.465795元，
其中已知用量7.771385元、未知上界1.694410元，余10.374205元。本轮新增1.092283元，包括
第二库0.589461元和全池6次重试0.502822元。请求预留按峰时cache-miss上界，结算按P4的
版本化时段/cache-hit-miss规则和服务商用量元数据，未知用量保留上界。当前权威费用为
共享账本attempt记录；旧缓存中的charged_upper只保留历史审计含义，不当账户实扣。

## 已阅读的评测来源

- Min等，2023，[FActScore](https://aclanthology.org/2023.emnlp-main.741/)：原子事实层面
  判断来源支持程度；本项目据此坚持全部claims逐项评审，不直接照搬其人物传记分数。
- Petroni等，2021，[KILT](https://aclanthology.org/2021.naacl-main.200/)：统一冻结知识源，
  同时评价任务与provenance；用于共同来源池与独立证据召回设计。
- Thorne等，2018，[FEVER](https://aclanthology.org/N18-1074/)：区分支持、反驳与信息不足并
  保留证据；本项目采用supported/unsupported/unclear，并另核验全池不足，不等同其人工标签。

以上原文摘要与官方论文页面已于2026-10-30读取；本项目指标与小样本设置是课程适配，
不声称复现三项基准的实验结果。
