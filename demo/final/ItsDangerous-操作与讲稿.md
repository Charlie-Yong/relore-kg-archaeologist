## 一、从课程提交包冷启动现场演示（教室演示机完整流程）

将 `HistoryKG-ItsDangerous-期末复核候选-v8.zip`（或课程提交时使用 `HistoryKG-ItsDangerous-课程实名提交版.zip`）解压至任意无中文空格阻塞的本地目录后（下以解压根目录为工作目录），依次执行：

### 1. 环境准备（仅首次在演示机执行）
1. 确认本机已有 Python 3.11+、Neo4j 5.26（默认 Bolt 地址 `bolt://127.0.0.1:7687`，与演示配置一致）及可用大模型通道凭据。
2. 安装依赖：
   ```bash
   python3 -m venv .venv
   .venv/bin/python -m pip install -r source/requirements.txt
   ```
3. 先启动本地 Neo4j 5.26 服务并确认端口 `7687` 可连接。

### 2. 一键导入冻结图谱并启动实时工作台（主演示方案）
在解压根目录运行（已自动绑定 `source/`、`frozen/`、`materials/itsdangerous.example.json` 与 `.streamlit/config.toml` 无 Deploy 极简外观）：
```bash
PYTHONPATH=source .venv/bin/python -m tools.serve_frozen frozen --config materials/itsdangerous.example.json --port 8517
```
浏览器打开 `http://127.0.0.1:8517` 即可见：
- 顶部已隐藏 Streamlit Deploy 干扰按钮；
- 表单外侧折叠区「查看已有时间线、依赖或版本关系」提供 **「快速实证（推荐 · 秒级）」**（默认）与 **「深度思考（慢速复杂推理）」** 切换及查询方式选择；无论是点击表单「查询」按钮还是点击下方 **4 枚一键演示按钮**（`决策原因`、`改动追溯`、`版本发布`、`假前提拒答`），都会即时采用当前选定的回答模式与查询方式；
- 每次回答后直接显示 **4 项实时遥测**（图谱子图检索 ms、模型有据问答 ms、证据路径数、核验原文数）、**五级可信度徽章**（`[官方API]` / `[Git实证]` / `[AST静态]` / `[文本声称]` / `[LLM抽取]`）及自动展开的 Top-2 冻结原文卡片。

### 3. 断网或模型波动一键离线回放兜底（零等待防翻车方案）
若教室断网、代理超时或 API 波动，立即 `Ctrl+C` 停止在线服务，改用验证通过的快问实时回放包启动同一界面：
```bash
HISTORYKG_REPLAY_FILE=materials/itsdangerous-replay.json PYTHONPATH=source .venv/bin/streamlit run source/app/main.py --server.address 127.0.0.1 --server.port 8517
```

### 4. 解压包内一键复核基线统计
```bash
PYTHONPATH=source .venv/bin/python -m tools.summarize frozen --records evaluation
```

## 二、5 分钟现场汇报 + 实机演示标准讲稿（逐页/逐环节节奏）

### 第 1 分钟：问题与方法（对应 PPT 第 1–4 页）
> “各位老师好，我们第九组做的是选题三‘GitHub 项目考古学家’。很多代码助手只看当前文件快照，回答不了三类跨文档考古题：第一，某个功能当初为什么弃用或拒绝（例如 `simplejson` 和加密载荷）；第二，作者在 PR 正文写了 `Closes #146`，平台到底合没合、改了哪个文件；第三，提交到底进了分支标签还是正式 Release。为此我们构建了 HistoryKG：坚持不执行目标仓库任何一行代码，只做只读 Git 差异、Python AST 静态解析与官方 REST/GraphQL 采集，再存入 Neo4j 5.26 + SQLite FTS5，每次问答用 Cypher 按需抓取局部子图并强制每句话锚定原文字节下标。”

### 第 2 分钟：两轮关键实证与对照（对应 PPT 第 5–7 页）
> “围绕期中老师关注的‘抽取到底准不准、比通用 Agent 和纯文本强在哪’，我们做了三项硬验证。第一，在决定抽取上，我们升级 `PROMPT_V2` 过滤 Dependabot 依赖升级噪声并区分提议和采纳：`orig30` 精确率从 40.0% 提至 **66.7%**、F1 提至 **0.6061**、Bot 误报从 8 降到 **0**；在不相交的 `heldout20` 盲测集上 Bot 误报也从 6 降到 **0**、保留理由由 3/8 升至 5/8（并如实披露含 1 条跨仓未决参考）。第二，对照 Codex 通用 Agent（`E` 组），我们用双口径公平比较：全部 6 题 `E` 组得 `10.5/17`（Q1/Q5 工具封装失效），即便只算正常作答的 4 题它能拿到 `95.45%`（`10.5/11`），但单题平均等 **262 秒**、消耗 **150 万到 443 万 Tokens**；而我们修通百炼零思考参数后的 `B_v2_fast` 在同一 6 题拿到 **17/17（100%）**，中位响应只要 **3.40 秒**，快了约 70 倍。第三，在 8 道从未见过的盲测题 `U1–U8` 上，我们用同一模型对比纯文本检索 `A_v2`（63.6%）：`B_v2_fast` 拿到 **90.9%（20/22，高出 27.3 个百分点）**，同时在 `U6` 分支标签区分问题上我们也如实指出了失分原因。”

### 第 3 分钟：大规模扩展性与第二仓库零改造迁移（对应 PPT 第 8–9 页）
> “为验证这不是只适配单仓的玩具：第一，我们在 Neo4j 里做了分批事务提交与 `cypher_subgraph` 改造，将图谱克隆压测至 `10x`（40,670 实体、116,740 关系），按需子图比全量快照提速 **7.80 倍**（23.52 秒降至 3.02 秒），且 `T1→T2→T3` 时序增量更新 `apply_delta` 耗时仅 `2.60 秒`（比全量重建 `3.09 秒` 快 `1.19 倍`）并保证指纹 100% 等价、三阶段探针零时间泄漏。第二，我们**不改一行业务代码**直接跑通第二仓库 `pallets-eco/blinker` 全历史构建，真实采集到了官方 GraphQL **`Closes = 5`** 条边，`B_v2_fast` 跨仓问答达到 **12/13（92.3%）**、中位 **1.48 秒**，在多跳链题 `BL2` 上拿到满分 3/3 而纯文本得 0/3。”

### 第 4–5 分钟：现场实机演示与自由提问（对应 PPT 第 10 页 & Live UI）
1. **点击一键演示 `决策原因`**（或现场演示老师提问）：
   - 指向顶部遥测栏：“图谱子图检索 ~860ms，模型问答 ~3s，共 50 条路径、47 条原文，全部有据可查。”
   - 指向右侧证据关系图与下方徽章：“请注意下面标明 `[官方API]` 和 `[Git实证]` 的强弱区分，点开原文可以直接核对 `git diff-tree` 差异和 `davidism` 的维护者评论。”
2. **演示假前提拒答**（点击 `假前提拒答` 或输入不存在特性）：
   - 展示系统会在约 `0.7s` 内明确告知冻结记录中查不到相关提交/决定，绝不编造 PR 编号或 Commit SHA。
3. **邀请老师现场出新题**：
   - 使用表单直接输入老师想问的任意 ItsDangerous Issue / PR / 版本 / 源码问题（保持默认 `快速实证` 模式即可在 2–4 秒内实机作答）。
